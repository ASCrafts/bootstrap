Django Template

Render hello.html with Django's render() method.

For one-click setup on Windows, double-click ex9-setup.bat.

Setup

mkdir hello_world
cd hello_world
python -m venv venv
python -m pip install django black
python -m django startproject helloworld_project .
python manage.py startapp pages

pages/views.py

from django.shortcuts import render

def hello_world(request):
    return render(request, "hello.html")

pages/urls.py

from django.urls import path
from pages.views import hello_world

urlpatterns = [
    path("hello/", hello_world, name="hello_world"),
]

pages/templates/hello.html

<html>
<head>
  <title>Hello Django!</title>
</head>
<body>
  <h1>Hello, World! from Django HTML</h1>
</body>
</html>

Include pages.urls in the project URLs and set DIRS to pages/templates in settings.py.

python manage.py runserver
# Open http://127.0.0.1:8000/hello/
