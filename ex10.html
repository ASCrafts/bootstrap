Django Student Model

Create a Student model, insert data into SQLite, display it, and delete it.

For one-click setup on Windows, double-click ex10-setup.bat.

URLs

/add_student/
/view_data/
/delete_data/

pages/models.py

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()
    email = models.EmailField(unique=True)

    def __str__(self):
        return self.name

pages/views.py

from django.http import HttpResponse
from django.shortcuts import render
from .models import Student

def add_student(request):
    Student.objects.get_or_create(
        email="ram@example.com",
        defaults={"name": "Ram", "age": 20},
    )
    return HttpResponse("Student added successfully!")

def view_data(request):
    return render(request, "view_data.html", {"my_data": Student.objects.all()})

def delete_data(request):
    Student.objects.all().delete()
    return HttpResponse("All data deleted successfully!")

Database commands

python manage.py makemigrations pages
